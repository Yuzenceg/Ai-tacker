Add complete user authentication to my application using Supabase Auth.

Requirements:

- Users can Sign Up, Log In, Log Out, and Reset Password.
- Sessions persist across page refreshes.
- Unauthenticated users are redirected to the login page.
- Authenticated users are redirected to the dashboard.

Security:

- Every user has their own private workspace.
- Goals, journal entries, memories, calendar data, and mood tracking must be tied to a user_id.
- Use Supabase Row Level Security (RLS).
- Users can only view, create, edit, and delete their own data.
- No user should ever be able to access another user's data.

Design:

- Match the existing website aesthetic.
- Warm cream background, soft beige tones, green accents, rounded corners, subtle shadows.
- Minimalist notebook/journal style.
- Do NOT create a generic SaaS or corporate login page.
